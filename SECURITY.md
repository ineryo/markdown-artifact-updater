# Security Policy

## Reporting a vulnerability

Do not disclose potential vulnerabilities publicly while this repository has no
public license or publication authorization. Report them privately to the
maintainers through the channel used to obtain the repository.

Please include a clear description, affected version or revision, reproduction
steps, and potential impact. Maintainers will acknowledge and assess the report
before deciding on remediation and disclosure.

## Supported versions

Only the current development revision is supported. In particular, report
containment, symlink, atomic-write, notebook-execution, or Python-call
allowlist bypasses as security issues.
